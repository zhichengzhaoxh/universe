About this model

The estimated transit depth uses δ = (planet radius / star radius)².

The curve uses a simplified center-crossing profile across relative positions −5 to +5. Noise is simulated as random scatter, and the displayed detection SNR is approximate. This is an educational illustration, not a fit to real observations.
